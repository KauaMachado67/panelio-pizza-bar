# Paneólio Pizza Bar

Website institucional responsivo para a Paneólio Pizza Bar, em Caldas da Rainha.

## Conteúdo

- Apresentação do restaurante
- Seleção de pratos em destaque
- Galeria visual
- Contactos, morada e ligação direta para reservas
- Links para Google Maps, Facebook e Instagram

## Executar localmente

Abra `index.html` no navegador. Não é necessário instalar dependências.

## Personalização

As imagens usam URLs do Unsplash como placeholders. Substitua-as por fotografias oficiais do restaurante em `styles.css`. Confirme também o menu, horários e links das redes sociais antes de publicar.
